# Projeto-Integrador-Frontend-JosePaulo
## Tema: Wiki sobre desenvolvimento para embarcados
Uma wiki para desenvolvedores inspirada em osdev.wiki, com o diferencial de ser feito pensando no desenvolvedor de embarcados e nas particularidades da área, como boostrapping de compiladores, cross-compiling para arquiteturas não-desktop, propriedades do hardware com que se está trabalhando, etc.

Curti bastante o projeto do colega. O tema é diferente e bem escolhido: uma wiki de sistemas embarcados fugiu dos catálogos que todo mundo fez, e as seções de Sistemas Operacionais e Hardware combinam direitinho com o assunto. O HTML está bem organizado, com main, section, footer, fieldset e legend, e os títulos seguem uma ordem que faz sentido. O formulário também ficou caprichado: todos os campos têm label ligado com for e id, e ele aproveita as validações do próprio HTML, como email, number com min e max, required, select e textarea. Outro ponto positivo é a organização dos arquivos. O CSS (reset.css e style.css) e o JavaScript (logica.js e script.js) estão separados, e não há nenhum estilo inline. As classes .card, .card-hero, .botao e .grade-secoes mostram que ele pensou em componentes reaproveitáveis. O README também explica o tema, o que ajuda quem chega no projeto. Sobre a Aula 06, ele cumpriu o que dá para ver no HTML: reset.css e style.css ligados na ordem certa, pelo menos 3 classes reutilizáveis, um ID e nenhum style="" no código. Na Aula 11, o script.js está carregado com defer no fim do body, como a atividade pede, e já existe uma section id="resultado" pronta para receber o resultado. Para melhorar um pouco, o primeiro ajuste é tirar a barra do começo dos caminhos dos arquivos (/css/reset.css), porque eles funcionam no Live Server mas quebram no GitHub Pages; o certo é css/reset.css. Outro ponto é o logica.js, que está no começo do body e sem defer, então a página só aparece depois de responder os prompt. Vale jogar ele para o fim do body com defer, como a Aula 09 pede. Também tem um h1 dentro da section de resultado, que pode sair para a página ficar com um título só e a seção vazia para o JavaScript preencher. Por último, faltaram alguns acentos em “nivel”, “Inspiracao” e “esta”, e o lang poderia ser pt-BR. No geral, é um projeto com uma boa ideia e uma base de HTML sólida. Com esses ajustes pequenos, ele fica bem alinhado com o que as Aulas 06, 07, 09 e 11 pedem.
