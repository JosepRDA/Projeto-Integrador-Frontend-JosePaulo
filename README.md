# Projeto-Integrador-Frontend-JosePaulo
## Tema: Wiki sobre desenvolvimento para embarcados
Uma wiki para desenvolvedores inspirada em osdev.wiki, com o diferencial de ser feito pensando no desenvolvedor de embarcados e nas particularidades da área, como boostrapping de compiladores, cross-compiling para arquiteturas não-desktop, propriedades do hardware com que se está trabalhando, etc.
